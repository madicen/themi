# Use Anthropic's Claude

Claude gives careful, thoughtful replies. It's paid by use, billed by Anthropic, so each
person uses their own key.

1. Go to the [Anthropic Console](https://console.anthropic.com) and make an account.
2. Add a payment method under **Billing**.
3. Under **API keys**, make a key and copy it.
4. In Themi, open [My AI](/ai) and paste the key into Claude.

You can keep Gemini on as well. Themi falls back to it if Claude doesn't answer.
