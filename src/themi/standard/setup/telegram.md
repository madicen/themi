# Make Themi's Telegram bot

Themi talks to the family through a Telegram bot of its own. Making one takes about two
minutes, and it's free.

1. Open Telegram and search for **@BotFather** (it has a blue tick).
2. Send it `/newbot`.
3. Give the bot a name people will see, like "Themi".
4. Give it a username that ends in `bot`, like `madicen_themi_bot`. It has to be unique.
5. BotFather answers with a token that looks like `123456789:AAH...`. Copy it.
6. Paste the token into **Telegram bot token** here and save.

Keep the token private: anyone with it can speak as your bot.

## After the restart

Each person pairs their Telegram with a code from the [Family page](/family). Once
they're paired, they can ask for a sign-in link to the website with /site.
