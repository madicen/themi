# Let Themi look things up

Themi can search the web and read a page when you ask it something it doesn't know, like
a shop's opening hours. It needs a key from a search service. Tavily's free plan is
plenty for a family.

1. Go to [tavily.com](https://tavily.com) and make a free account. No card is needed.
2. On your Tavily dashboard, copy your API key. It starts with `tvly-`.
3. Paste it into **Tavily API key** here and save.
4. Press **Test** to try one search.

The free plan gives 1,000 searches a month.

## Firecrawl instead

[Firecrawl](https://firecrawl.dev) works too, with about 500 free searches a month. Its key
goes under the advanced settings. With both keys saved, choose which one Themi uses.
