# Make pictures with Cloudflare

Cloudflare Workers AI has a picture model with a free daily allowance. Themi uses it only
for making pictures, like a picture for each step of a guided task.

1. Make a free account at [cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Copy your **Account ID** from the dashboard.
3. Make an API token with the **Workers AI** permission and copy it.
4. In Themi, open [My AI](/ai) and add a Cloudflare backend for pictures: the Account ID
   is its address and the token is its key.
