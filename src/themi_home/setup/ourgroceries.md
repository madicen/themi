# Show the grocery list in OurGroceries

Themi keeps its own grocery list. With this on, the list shows in the OurGroceries app too,
and changes there come back into Themi.

1. Enter the **email** and **password** of the OurGroceries account the family shares.
2. Enter the name of the shared list, if it isn't called "Groceries".
3. Save, and press **Test**: Themi reads the list once.

OurGroceries has no official way in, so this uses the one its app uses. If it changes, the
mirror stops and Themi's own list carries on.
