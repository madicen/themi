# The litter box, through CatGenie

A CatGenie can tell Themi about errors and when its sani-solution runs low. CatGenie has no
official way in, so this may stop working when they change things. Themi only reads it.
There's nothing to fill in here.

## After the restart

On [Accounts](/accounts), an admin enters the phone number the CatGenie app signs in with,
presses **Send code**, and enters the code that's texted to it.
