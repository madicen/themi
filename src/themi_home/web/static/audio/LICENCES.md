# Built-in loops for the session page (BD5a)

Every loop here is original: synthesised from code by `tools/make_loops.py` (ffmpeg's
noise and expression sources), with no samples or recordings from anywhere else. They are
dedicated to the public domain under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/).

| File | What it is | Licence |
| --- | --- | --- |
| lofi.m4a | Soft keys over a slow 80 BPM beat and a little crackle | CC0 1.0, made for Themi |
| rain.m4a | Filtered pink noise that swells like steady rain | CC0 1.0, made for Themi |
| soft-piano.m4a | Four slow chords at 66 BPM with a gentle echo | CC0 1.0, made for Themi |
| brown-noise.m4a | Brown noise, low-passed | CC0 1.0, made for Themi |
