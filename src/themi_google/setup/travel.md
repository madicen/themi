# Travel times with live traffic

Themi works out how long it takes to get to calendar events and says when it's time to get
ready. Without a key it finds places on OpenStreetMap and estimates from the distance. With
a free TomTom key it uses live traffic.

1. Make a free account at [developer.tomtom.com](https://developer.tomtom.com). The free
   plan is plenty.
2. Copy the API key from your dashboard.
3. Paste it into **TomTom API key** here, save, and press **Test**.

The home address is set on the [Family page](/family).
