# The morning message

Themi starts your day with one message: a good morning and what's on your calendar today.
Nothing else arrives with it.

```
Good morning, Erin.
Thu 22 Oct:
- 10-11 am: Dentist

[ Today's tasks ]   [ Email ]
[ Everything else ] [ Just one thing ]
```

The buttons are there if you want more. Tap one whenever you like, or don't:

- **Today's tasks**: what's due today, with a tick for each.
- **Email**: anything from your inbox that Themi held overnight (cards to approve, the email
  audit).
- **Everything else**: any other messages Themi held overnight (meal ideas, groceries...).
- **Just one thing**: a single task to start with. The rest are kept.

A button only shows up when there's something behind it. After you tap one, it goes away
from the message, so you can see what you've looked at.

**None of this uses up your daily message limit.** Only the morning message itself counts.
Anything you open with a button is an answer to your tap.

**If you don't tap anything**, Themi offers what's still waiting once more at noon (or at
5 pm if you're busy at noon). That's the last reminder for the day. Anything still waiting
after that shows up behind tomorrow's buttons.

**Urgent things still come right away.** That includes urgent email, a reminder you set for
a time, a medicine, and a task you set for a time today.

## Setting it up

On the website, under **Settings → My calendars**, set the time for "A good-morning message
with today's calendar". Leave it blank to turn it off. With it off, Themi's mornings work as
they did before. Tick "Send it on days with nothing on and nothing waiting, too" if you want
a good morning even on empty days.
